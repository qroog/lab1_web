Основные возможности
- Каталог товаров 
- Корзина с добавлением/удалением товаров
- Оформление заказа
- Адаптивный дизайн 

Структура проекта
- index.html - главная страница
- style.css - стили
- script.js - основная логика
- data.js - данные товаров
- Images/ - папка с изображениями
